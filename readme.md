# 股票投资组合预测竞赛总结

## 一、赛题背景

基于沪深 300 指数成分股的历史股价数据，建立机器学习模型，预测未来一周收益最大的股票组合（不超过 5 只），并分配权重。

## 二、输出格式

提交 `result.csv`（UTF-8 编码），示例：

```csv
stock_id,weight
000408,0.2
000975,0.2
002028,0.2
600372,0.2
600036,0.2
```

- 不超过 5 只股票
- 每行：股票代码,权重
- 权重和 ≤ 1，剩余部分为现金（收益率为 0）

## 三、变量定义
| 符号 | 含义 |
|------|------|
| $n$ | 股票数量（≤ 5） |
| $w_i$ | 第 $i$ 只股票的权重 |
| $P_{i,T+1}^{\text{open}}$ | 第 $i$ 只股票在 $T+1$ 日开盘价（买入价） |
| $P_{i,T+5}^{\text{open}}$ | 第 $i$ 只股票在 $T+5$ 日开盘价（卖出价） |
| $w_{\text{cash}}$ | 现金权重 = $1 - \sum w_i$ |

## 四、收益计算公式

**单只股票收益率**：
$$
R_i = \frac{P_{i,T+5}^{\text{open}} - P_{i,T+1}^{\text{open}}}{P_{i,T+1}^{\text{open}}}
$$

**组合总收益率**（现金收益率为 0）：
$$
R_{\text{total}} = \sum_{i=1}^n \left( w_i \times R_i \right)
$$

## 五、评估与排名
1. 组合总收益率必须 **高于基准程序** 才能参与排名
2. 按总收益率从大到小排序

## 六、其他要求
- 数据：公开免费可获取（如 baostock），需说明来源
- 预训练模型：非商业化公开数据训练 / 2026年4月1日前公开发表
- 可复现性与创新性作为参考
- 收益率低于基准无获奖资格
